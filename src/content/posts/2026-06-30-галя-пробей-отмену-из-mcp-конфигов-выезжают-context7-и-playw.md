Недавно у них появились альтернативы через CLI-скиллы.

Context7 теперь ставится через `npx ctx7 setup` и работает как скилл — агент просто дёргает CLI когда нужна документация по библиотеке. Без MCP-сервера, без постоянного процесса. 

Playwright MCP для базовой браузерной автоматизации заменяется agent-browser от Vercel — CLI, написанный на Rust, который жрёт в разы меньше токенов.

**В чем тут экономия**: MCP это процесс-демон с протоколом.

Скилл это SKILL.md файл, который говорит агенту «запусти вот эту команду». Агент читает инструкцию и дёргает CLI. Накладных расходов на лишний процесс в памяти нет.

Но почистить mcp конфиг под ноль не выйдет. Serena, например, никуда не денется — она крутит живой LSP-сервер с состоянием, который индексирует проект и держит граф зависимостей в памяти. Такое скиллом не заменить.

И отдельно ко вчерашнему кейсу, для него mcp подход пока что будет надежнее, до тех пор, пока не выкатят cli для чтения ClickHouse. Хотя, да, по сути ему не нужен постоянно поднятый mcp.

**Следим за новинками, переобуваемся осмысленно, а не потому что так модно в этом сезоне.**
